# JAN Carrousel module v4505 - English

This folder can be extracted from the project zip and run independently.

Start locally with:

```text
carrousel/index.html
```

English entry:

```text
carrousel/index-en.html
```

## Contents

- `index.html` - standalone Dutch carrousel view.
- `index-en.html` - standalone English carrousel view.
- `carrousel.css` - editable source CSS for a future non-inline variant.
- `carrousel.js` - editable source JS for a future non-inline variant.
- `slides.json` - editable slide index.
- `slides/` - separate source images and text files.

This folder can be returned as a whole and placed back in the project zip under `carrousel/`.
