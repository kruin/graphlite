# SOURCE_CHANGES v2.0.0-rc.19

## Herstel

- Topmenu is op alle interfaces exact twee rijen.
- Rij 1: Zin, Bijwoord, Syntax/FT, Interface, Projecties, LOG-volgorde.
- Rij 2: NL/EN, Help, Config.
- Tweede rij heeft een eigen verticale tussenruimte.
- Desktop toont voortaan eveneens rij 2.
- Mobile-preview gebruikt de framebreedte en laat geen items rechts buiten het frame lopen.
- Uitklappanelen openen onder de volledige tweerijige balk.
- Dynamische topbar-meting blijft leidend voor Play-balk en canvashoogte.
