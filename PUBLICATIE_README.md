## Feiten die in deze release kloppen

- OpenGraph Notation scheidt de centrale structuur van de lineaire
  woordvolgorde op LEX.
- OGN Basis blijft de uitgangspositie; toepassingen zijn afzonderlijk
  schakelbaar wanneer hun voorconfig gereed is.
- Bijwoorden is een optionele toepassing boven op LEX- en LOG-insertie.
- Config kan per LEESMIJ-item de navigatietitel en tekst in NL/EN aanpassen en
  het item op **Tonen: ja/nee** zetten.
- Lokale PNG-, JPEG-, WebP- en GIF-bestanden kunnen via
  **Bestanden & export** als carousel-slide worden ingevoegd.
- Dezelfde Config-savebediening is op ieder Config-onderdeel beschikbaar.
- Iedere projectzip bevat een standaardconfig en een afzonderlijke
  user-config; de user-config mag de standaardinstellingen overschrijven
  zonder het standaardbestand te vervangen.
- rc.43 is een release candidate; noem het geen definitieve stabiele release
  zolang de handmatige controle niet is afgetekend.

Aanbevolen tekst:

```text
I am developing OpenGraph Lite Viewer, a browser-based viewer for OpenGraph Notation.

The central idea is that structural relations and linear word order should not be forced into the same drawing. The central graph represents structure; LEX independently represents the sentence order. SYNT and LOG provide additional named projections.

rc.43 is a release candidate. Its Config now lets users show or hide each README topic, edit the Dutch and English topic content, insert a local image as a carousel slide, and save from every Config section. A project zip can carry a user config alongside the bundled default; the user layer overrides matching default settings. OGN Base remains usable without optional applications.

Demo: [LIVE_DEMO_URL]
Source/release: [SOURCE_OR_RELEASE_URL]

I would especially appreciate criticism of:
1. whether the notation is understandable without prior context;
2. the distinction between structure, LEX, SYNT, and LOG;
3. the mobile and desktop layout;
4. the editable in-viewer documentation.

Disclosure: I am the developer. This is a request for technical and linguistic feedback, not a claim that rc.43 is a stable final release.
```

## GitHub-releasebeschrijving

```text
## OpenGraph Lite Viewer v2.0.0-rc.43

Release candidate for manual validation.

### New

- Editable README navigation titles and NL/EN topic content.
- Per-topic Show: yes/no; topics are hidden rather than deleted.
- Local PNG/JPEG/WebP/GIF import as an embedded README carousel slide.
- One shared Config save bar available from every Config section.
- A project user config alongside the bundled default, with user values taking precedence.
- Platform-ready publication copy included in `PUBLICATIE_README.md`.

### Preserved

- OGN Base remains the default profile.
- Optional applications remain separated from pre-configuration.
- README topic and carousel overrides remain Config data and are not added to OPN document data.

### Test

Use the included release and rc.43 test scripts. Manual approval is still required for desktop, mobile portrait, and mobile landscape.
```

## Beeld en toegankelijkheid

- Gebruik bij voorkeur één rustig beeld waarop boom én relevante as leesbaar
  zijn.
- Neem geen volledige Configpagina als kleine social-afbeelding; uitsneden
  zijn beter leesbaar.
- Voeg op ieder platform een concrete alt-tekst toe, bijvoorbeeld:

```text
OpenGraph Lite Viewer met een centrale syntaxboom en afzonderlijke blauwe LEX-, groene SYNT- en paarse LOG-projecties.
```

- Controleer voor publicatie of de getoonde versie in beeld, tekst, live URL
  en download allemaal **v2.0.0-rc.43** zijn.
