# SOURCE_CHANGES_V2.0.0-rc.11

## Topmenu

- De algemene knop `Menu` is verwijderd.
- Main toont één topmenubalk met acht zichtbare hoofditems: Zin, Bijwoord, Syntax/FT, Projecties, LOG-volgorde, NL/EN, Help en Config.
- Zin, Bijwoord, Syntax/FT, Projecties en LOG-volgorde openen elk rechtstreeks een breed paneel.
- NL/EN, Help en Config zijn directe acties.
- Er zijn geen geneste submenu’s.
- Desktop gebruikt één rij waar ruimte is; smalle schermen gebruiken een stabiele tweede rij.

## Behouden

- Alle assen zijn standaard zichtbaar.
- FT blijft de tweede centrale view.
- LOG blijft uitsluitend de zuidas.
- Dunne boomlijnen en boxcontouren; alleen projectielijnen zijn iets zwaarder.
