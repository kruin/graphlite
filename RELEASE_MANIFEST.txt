1. Syntax

Projection contract:
LEX west / SYNT east / LOG south
LOG is not a central view.
Old central_opn=functional input is accepted and migrated to ft.

Chosen Source-axes solution:
- projection selector in the top bar, outside the SVG canvas;
- Source can combine LEX, SYNT and LOG independently;
- Assen is shown only while Source is active;
- LOG action is visible only when LOG is visible.

Compact topbar contract:
- one fixed row;
- Sentence, Adverb, View and Projection remain directly available;
- Language, Help and Config are grouped in one readable Menu popover;
- narrow layouts may hide static labels, not the selected values or accessible labels;
- Menu/Assen popovers do not change canvas dimensions or viewBox.

Stable viewport contract:
- Alle / Bron / LEX / SYNT / LOG use one identical viewBox;
- Syntax / FT use the same union frame;
- projection switching preserves pan and zoom;
- Play bar height is fixed; disabling Growth cannot move the grid.
