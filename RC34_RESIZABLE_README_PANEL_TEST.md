# RC34 resizable README panel test

1. Open LEESMIJ/README.
2. Verify the topic list and selected text are both visible.
3. Drag the separator toward the topic list: the text panel grows.
4. Drag it toward the text panel: the text panel shrinks.
5. Verify neither panel can be reduced to zero.
6. Test desktop and mobile landscape: horizontal dragging.
7. Test mobile portrait: vertical dragging.
8. Focus the separator and test arrow keys, Home and End.
9. Close and reopen README in the same session; verify the chosen split is retained.
10. Reload or open another topic and verify navigation and scrolling still work.
