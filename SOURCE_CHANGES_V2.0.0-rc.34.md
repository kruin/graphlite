# Source changes v2.0.0-rc.35

## Resizable LEESMIJ/README text panel

- Added one draggable separator between the README topic list and selected text.
- Desktop and mobile landscape resize horizontally.
- Mobile portrait resizes vertically.
- Pointer and touch dragging are supported.
- Keyboard control: arrow keys, Home and End.
- Minimum and maximum sizes keep both panels usable.
- The selected size is retained in `sessionStorage` for the current browser session.
- The active topic and its scroll position behavior remain unchanged.

## Compatibility

- No changes to graph layout, lexical placement, projections, Config saving or release publishing.
